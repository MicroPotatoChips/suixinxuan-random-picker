# 随心选

一款精致的扭蛋机风格随机抽选网页。无需安装、无需服务器，打开网页即可使用，适合课堂点名、活动抽奖、会议发言顺序等场景。

## 在线体验

[打开「随心选」](https://suixinxuan-lucky-picker.jimmy43991.chatgpt.site)

## 功能特点

- 支持自定义人员名单，最多 50 人
- 名单自动保存在当前浏览器，刷新或关闭后仍会保留
- 支持不重复抽取，抽中过的人会暂时移出本轮
- 可随时重置本轮，保留原名单重新开始
- 扭蛋翻滚、旋钮转动、结果出球和彩纸庆祝动画
- 支持手机、平板和桌面浏览器
- 使用浏览器安全随机数生成器进行抽选
- 纯前端单页，无广告、无追踪、不会上传名单

## 使用方法

1. 在右侧名单框中输入名字，每行一人，也可使用逗号分隔。
2. 点击“保存并装入扭蛋”。
3. 点击黄色旋钮开始随机抽取。
4. 如开启“不重复抽取”，本轮已经抽中的人不会再次出现。
5. 点击“重置本轮”即可让所有人重新参与。

也可以使用 `Ctrl + Enter` 快速开始抽取。

## 本地运行

本项目没有依赖和构建步骤。下载仓库后，直接用浏览器打开 `index.html` 即可。

也可以使用任意静态文件服务器：

```bash
npx serve .
```

## 技术说明

- HTML、CSS、原生 JavaScript
- `localStorage` 保存名单、选项与抽取记录
- `crypto.getRandomValues()` 生成随机结果
- 响应式布局与减少动态效果偏好支持

## 数据与隐私

人员名单仅保存在使用者当前设备的浏览器中，不会上传到服务器。清除浏览器站点数据后，本地名单也会被删除。
