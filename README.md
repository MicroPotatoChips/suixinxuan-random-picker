# 随心选

一款精致的随机抽选网页，包含扭蛋机和单格老虎机两种模式。无需安装、无需服务器，打开网页即可使用，适合课堂点名、活动抽奖、会议发言等场景。

## 在线体验

[打开「随心选」](https://suixinxuan-lucky-picker.jimmy43991.chatgpt.site)

## 功能特点

- 扭蛋机：自定义人员名单，最多 50 人；支持不重复抽取和重置本轮
- 单格老虎机：一次只滚动并显示一个结果
- 提供 7 个独立数据模块，每个都能自行命名、编辑内容，最多 50 项
- 可以任选一个或多个模块加入老虎机抽选池
- 名单、模块内容、勾选状态和当前模式自动保存在本机浏览器
- 扭蛋翻滚、老虎机滚动和彩纸庆祝动画
- 适配手机、平板和桌面浏览器，并支持减少动态效果偏好
- 使用浏览器安全随机数生成器；纯前端、无广告、无追踪

## 使用方法

### 扭蛋机

1. 在右侧输入参与名单，每行一人，也可用逗号分隔。
2. 点击“保存并装入扭蛋”，再点击黄色旋钮抽选。
3. 可开启“不重复抽取”；点击“重置本轮”可重新开始。

### 单格老虎机

1. 点击左侧上方的“单格老虎机”。
2. 在右侧点击模块名称，修改名称和内容；每行一项，也可用逗号分隔。
3. 勾选要参加抽选的模块，可同时勾选多个。
4. 点击“开始抽选”，老虎机会滚动并停在一个随机结果。

两种模式都支持 `Ctrl + Enter` 快速抽选。老虎机默认从已勾选模块的所有条目中随机抽取；相同内容若分别存在于不同模块，会分别计入抽选池。

## 本地运行

本项目没有依赖和构建步骤。下载仓库后，直接用浏览器打开 `index.html` 即可。也可以使用任意静态文件服务器：

```bash
npx serve .
```

## 技术说明

- HTML、CSS、原生 JavaScript
- `localStorage` 保存名单、模块、选项和抽取记录
- `crypto.getRandomValues()` 生成随机结果
- 响应式布局与减少动态效果偏好支持

## 数据与隐私

输入内容仅保存在当前设备的浏览器中，不会上传到服务器。清除浏览器站点数据后，本地保存的内容也会被删除。
